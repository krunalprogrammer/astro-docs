Saasdesk (Astro)

Saasdesk is a marketing site for a payroll & HR product, built around a bright, pastel-accented SaaS/startup layout — a hero with a product screenshot, a benefits strip, a feature grid, use-case blocks, a testimonial, integrations, a client-review carousel, tiered pricing, and an FAQ accordion, rounded out with login/signup utility pages.

Properties

Property Value
Tier Free
Category SaaS / startup (payroll & HR)
Body font General Sans (variable, weights 200–700), self-hosted via Astro's Fonts API
Display font General Sans — same single family used for headings and body
Brand accent / colors Accent #00acca, heading/dark #2b2b46; pastel section backgrounds #fff3e6 (orange), #e6fbff (blue), #e6fff0 (green), #f8ffe6 (yellow), #e6e8ff (purple), #f4d4eb (pink)

Included pages

  • src/pages/index.astro — homepage: Hero, Benefits, Features, UseCases, Testimonial, Integrations, Reviews, Pricing, FAQs, ClientLogos, ForTeam, Footer
  • src/pages/login.astro — login form (work email + password) alongside the shared payroll/HR headline and trial-terms checklist panel
  • src/pages/signup.astro — signup form (name, email, password, confirm password) using the same shared panel as the login page

What makes this template different

  • Scroll-collapsing header: Layout.astro uses GSAP to animate .header to zero height on scroll and pins .navbar with an is-sticky class, via an rAF-throttled scroll listener
  • One shared tab/accordion engine (src/scripts/tabs.js) drives the toggle behavior in FAQs.astro, Benefits.astro, and Pricing.astro from a single place
  • Client-review carousel in Reviews.astro built with Swiper, with custom prev/next arrow controls
  • Hand-built mobile nav drawer in Navbar.astro: transform-based slide-in panel, dimmed overlay, animated hamburger-to-X lines, and a body scroll lock — implemented independently of the source design's dormant Webflow IX2 attributes
  • Self-hosted variable font (General Sans, weights 200–700) loaded through Astro's built-in Fonts API (astro:assets Font component) rather than a CDN
  • Color-coded pastel section backgrounds (CSS custom properties in theme.css) used to visually separate Benefits/Features/Use-Cases blocks instead of borders or shadows
  • A gulp task (npm run zip) packages the theme into a distributable zip for marketplace submission

What's next

  • Site-wide config (brand name, logo, social links, contact info, app-store links, copyright): src/data/site-config.js
  • Colors: public/css/theme.css — CSS custom properties under :root (--color--accent, --color--dark, and the pastel section colors)
  • Fonts: astro.config.mjs (the fonts array — currently one local General Sans variable font) plus the font file under src/assets/fonts/
  • Section copy: src/data/*.js (features.js, faqs.js, reviews.js, pricing.js, footer.js, benefits.js, use-cases.js, for-team.js, client-logos.js) — each section component imports its matching data file
  • Add a new page: drop an .astro file into src/pages/ (file-based routing), reusing Navbar/Footer from src/components/ for consistent chrome
  • Add a new homepage section: build a component in src/components/ and import/place it in src/pages/index.astro
